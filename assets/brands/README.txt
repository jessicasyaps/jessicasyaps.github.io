Real brand logo files live here, referenced from data.js's `brands` array:

  trip.webp   — Trip.com logo
  temu.png    — Temu logo
  tocobo.png  — Tocobo logo

Any image format works (SVG, PNG, WebP, AVIF, ...) — just make sure the path
in data.js's `brands` array matches the actual filename and extension.

If a logo file is ever missing, that tile automatically falls back to a clean
text wordmark of the brand name — nothing breaks.
